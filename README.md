# Нейроставки — UI-прототип

Аналитический сервис для ставок: нейросеть собирает информацию о матче, оценивает вероятности исходов, сравнивает их с котировками семи российских букмекеров и показывает валуй (ожидаемую доходность) и лучший коэффициент.

**Демо:** https://serjnsk.github.io/neirostavki-prototype/

## Что внутри

- `index.html` — главная страница: hero, панель «Топ по валую» со слайдером переворачивающихся карточек событий, список всех событий с фильтрами. Один самодостаточный файл, логотипы встроены.
- `assets/logos/` — исходники логотипов и флагов для следующих страниц.

## Логика карточки

- Наш кэф = 1 / наша вероятность.
- Рынок = консенсус 7 БК без маржи.
- Валуй = наша вероятность × лучший кэф − 1.
- На обороте карточки — разложение «рынок → факторы → наша оценка», движение линии, источники.

Прототип, данные демонстрационные. Сервис не принимает ставки. 18+
