# Нейроставки — UI-прототип

Аналитический сервис для ставок: нейросеть собирает информацию о матче, оценивает вероятности исходов, сравнивает их с котировками семи российских букмекеров и показывает валуй (ожидаемую доходность) и лучший коэффициент.

**Демо:** https://serjnsk.github.io/neirostavki-prototype/
**Страница события:** https://serjnsk.github.io/neirostavki-prototype/event.html?id=1

## Страницы

- `index.html` — главная: hero, панель «Топ по валую» со слайдером переворачивающихся карточек событий, список всех событий с фильтрами.
- `event.html?id=N` — страница события: прогноз и сравнение исходов с рынком, разбор «почему», линия стандартных ставок против 7 БК (исходы, двойные шансы, форы, тоталы — как у Фонбета), динамика оценки, дополнительные рынки, форма, составы, статистика, источники, калькулятор.

## Структура

- `assets/app.css` — общие стили и токены.
- `assets/data.js` — события, модель (консенсус рынка без маржи, валуй, стандартные ставки), форматирование.
- `assets/app.js` — шапка и подвал, карточка события, строка списка, подсказки, динамический фон.
- `assets/logos.js` — логотипы и флаги в data URI; исходники в `assets/logos/`.
- `serve.py` — локальный сервер без кэша для просмотра правок.

## Как смотреть локально

```bash
python3 serve.py
```

Затем откройте http://127.0.0.1:8765.

## Логика данных

- Наш кэф = 1 / наша вероятность.
- Рынок = консенсус 7 БК без маржи.
- Валуй = наша вероятность × лучший кэф − 1.
- Форы и тоталы считаются той же моделью, что и исход 1/X/2 (распределение Пуассона для футбола и хоккея), поэтому все рынки согласованы.
- На обороте карточки и в блоке «Почему» — разложение «рынок → факторы → наша оценка».

Прототип, данные демонстрационные. Сервис не принимает ставки. 18+
